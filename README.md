# عبد الرحمن ياسر الأسيوطي — موقع شخصي

واجهة عربية RTL احترافية لموقع شخصي لمطور ويب. لا تحتاج أي أدوات بناء أو حزم خارجية.

## التشغيل محليًا

```bash
python3 -m http.server 4173
```

ثم افتح `http://localhost:4173`.

## تخصيص سريع

- **الصورة الشخصية:** اضغط «أضف صورتك» داخل الواجهة لتجربتها محليًا، أو استبدل `assets/portrait-placeholder.svg` بصورة ثابتة مع الحفاظ على الاسم نفسه في `index.html`.
- **معلومات التواصل:** نموذج التواصل ينسخ ملخص الرسالة كي يبقى مفيدًا قبل ربط الموقع بخدمة بريد. يمكن ربطه بخدمة الاستضافة أو Formspree عند توفر بريد/قناة التواصل الخاصة بك.
- **المحتوى:** النصوص ونماذج الواجهات موجودة في `index.html` وسهلة التعديل.
