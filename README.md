# غرفة 3D خفيفة — منظور أول

غرفة ثلاثية الأبعاد بزاوية منظور أول، مكتوبة بـ Canvas 2D فقط. لا تستخدم WebGL أو محرك ألعاب أو نماذج وصور خارجية.

## الأداء

- محرك ray-casting صغير يرسم الجدران والأرضية والعناصر الإجرائية.
- دقة Canvas محددة تلقائيًا بحد أقصى `410,000` بكسل لتناسب الأجهزة الضعيفة.
- لا توجد أي حلقة رسوم متحركة أثناء السكون؛ الرسم المستمر يعمل فقط أثناء المشي.
- المشهد كله ملفات HTML/CSS/JavaScript فقط.

## التحكم

### الكمبيوتر

- انقر داخل الغرفة ثم حرّك الفأرة للنظر حولك 360 درجة.
- `W` / `A` / `S` / `D`: مشي وتحرك جانبي.
- السهمان ↑ و ↓: تقدم ورجوع.
- السهمان ← و →: التفات.

### الهاتف

- اسحب من **الجزء الأيسر** من الشاشة للمشي.
- اسحب من **الجزء الأيمن** للنظر حول الغرفة.

## التشغيل على المنفذ 3000

```bash
python3 -m http.server 3000 --bind 0.0.0.0
```
