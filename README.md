# غرفة 3D خفيفة

تجربة غرفة ثلاثية الأبعاد بسيطة وتفاعلية، مصممة لتعمل بسلاسة على الأجهزة الضعيفة.

## التقنية

- Canvas 2D فقط — لا توجد مكتبات أو WebGL أو ملفات صور ثقيلة.
- الرسم يحدث عند تحميل الصفحة أو تغيير الحجم أو تفاعل المستخدم فقط، وليس في حلقة رسوم مستمرة.
- دقة الـ Canvas محدودة تلقائيًا إلى حد آمن للأجهزة ذات الشاشات عالية الدقة.
- السحب، اللمس، أزرار الاتجاه، ولوحة المفاتيح كلها مدعومة.

## التشغيل محليًا على المنفذ 3000

```bash
python3 -m http.server 3000 --bind 0.0.0.0
```

ثم افتح `http://localhost:3000` من نفس بيئة التشغيل.

## عناصر التحكم

- اسحب داخل الغرفة بالفأرة أو الإصبع لتدوير المنظور.
- استخدم أسهم لوحة المفاتيح بعد الضغط داخل المشهد.
- `+` و `-` للتقريب والإبعاد، و`R` لإعادة زاوية البداية.
- زر **إضاءة** يبدّل بين الوضع النهاري والمسائي.
