# 🎮 Season Runner — مغامرة الفصول

**Endless Runner 2D** بفصول متغيرة! العب **على المتصفح** أو **حمّل APK** للأندرويد.

| | |
|---|---|
| 🎮 النوع | Endless Runner 2D (فردي) |
| 🛠️ التقنية | HTML5 Canvas + WebAudio (بدون مكتبات خارجية) |

- 🌸 **الربيع** — أغصان متدلية (انزلاق)، نحل طائر، برك طين، زهور متفجرة
- ☀️ **الصيف** — أعمدة نار، صبار متحرك، عدسات شمسية، عواصف رملية
- 🍂 **الخريف** — أكوام ورق تخفي عوائق، دوامات هواء، فطر متفجر، ثعالب
- ❄️ **الشتاء** — كتل جليد تسقط (بتحذير)، رجال ثلج متحركون، دببة نائمة تطاردك!

## 🚀 التشغيل محليًا

```bash
# أي سيرفر ثابت بسيط
cd web
python3 -m http.server 8000
# افتح http://localhost:8000
```

## 📱 تحميل APK للأندرويد

1. افتح [Releases](https://github.com/Abdelrahmanluxor2024/abdo/releases) في الربرة
2. حمّل `SeasonRunner-v1.0.0.apk` على موبايلك
3. ثبّته (اسمح بتثبيت التطبيقات من مصادر غير معروفة من الإعدادات)
4. استمتع! 🎉

> الـ APK يُبنى تلقائيًا في GitHub Actions عند عمل tag جديد:
> ```bash
> git tag v1.0.1 && git push origin v1.0.1
> ```

## 📥 التحميل والتشغيل بدون إنترنت (نسخة المتصفح)

اللعبة **تعمل بدون نت نهائيًا** — كل الخطوط والأصوات والكود مدمجة داخل الملفات،
والتخزين محلي. حمّل الملف مرة واحدة واشغلها في أي وقت.

### خطوات التحميل:
1. افتح صفحة الملف: [`SeasonRunner-v1.0.0-web.zip`](SeasonRunner-v1.0.0-web.zip)
   (أو من صفحة الريبو الرئيسية → اضغط على الملف الأخضر)
2. اضغط **Download** (أو **View raw**)
3. فك الضغط على الكمبيوتر أو الموبايل
4. افتح الملف `index.html` داخل المجلد بأي متصفح (Chrome / Edge / Firefox)
5. استمتع! 🎉 — لا يحتاج إنترنت ولا تثبيت

> 💡 على الموبايل: انسخ المجلد إلى هاتفك وافتح `index.html`،
> أو ثبّت تطبيق ملفات يدعم فتح HTML (مثل فتحه في Chrome من مدير الملفات).
