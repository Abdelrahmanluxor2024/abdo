# 🎮 Season Runner — مغامرة الفصول
## وثيقة تصميم اللعبة (Game Design Document)

**الإصدار:** 1.0.0 — **الحالة:** مُنفَّذ (Implemented)
**المنصة المستهدفة:** أندرويد APK + متصفح (HTML5)
**الفئة العمرية:** 7+ | **اللاعبون:** لاعب واحد | **مدة الجلسة:** 2–5 دقائق | **الحجم:** أقل من 5 MB

---

## 1) المفهوم العام (Concept)

**Season Runner** لعبة جري لا نهائية (Endless Runner) ثنائية الأبعاد، بطلها **نورو (Nuro)**،
روح الطبيعة الصغيرة المتوهجة التي تحرس **جوهرة التوازن**. يسرقها **ملك الفوضى (Chaos King)**
فتنكسر الجوهرة إلى شظايا 💎 وتختلط الفصول الأربعة: صيفٌ يحرق الربيع، وثلجٌ يغطي الخريف.
يجري نورو عبر الفصول الأربعة، يجمع شظايا الجوهرة وأوراق الأشجار، ويعيد التوازن للطبيعة.

> **الهدف:** الجري لأبعد مسافة ممكنة، جمع أكبر عدد من الأوراق 🍃 وشظايا الجوهرة 💎،
> فتح الفصول الأربعة، وتحقيق أعلى نتيجة.

---

## 2) الفصول الأربعة (The Seasons)

تتغير الفصول دوريًا: **🌸 الربيع → ☀️ الصيف → 🍂 الخريف → ❄️ الشتاء** ثم تعود.

| الخاصية | 🌸 الربيع | ☀️ الصيف | 🍂 الخريف | ❄️ الشتاء |
|---|---|---|---|---|
| السرعة | متوسطة (أساس) | سريعة (+20%) | متوسطة مع انزلاق طفيف | بطيئة لكن زلقة جدًا (جليد) |
| الألوان | أخضر ووردي | ذهبي وبرتقالي | برتقالي وبني | أزرق جليدي وأبيض |
| الأجواء | فراشات وزهور | غبار وشمس حارقة | أوراق متساقطة وضباب | تساقط ثلوج |
| الموسيقى | مرحة 102 BPM | حماسية 134 BPM | حنينية 92 BPM | هادئة 74 BPM |

**قواعد التحول:**
- تحول كل **40 ثانية** (ضمن نطاق GDD: 30–45 ثانية).
- التحول يشمل: تغيير كامل للوحة الألوان (تلاشي تدريجي)، تبديل الموسيقى (Crossfade)،
  تبديل العوائق، تغيير الفيزياء (الجاذبية/السرعة/الاحتكاك)، وانتقال بصري يشبه **تمزق الورق**.
- الصعوبة تزداد مع الوقت (سرعة متدرجة حتى ~2×).

## 3) التحكم (Controls)

| الإجراء | اللمس | الكيبورد |
|---|---|---|
| قفز | ضغطة واحدة 👆 | مسافة / ↑ |
| قفز مزدوج | ضغطتان سريعتان | ضغطتان |
| انزلاق | سحب لتحت 👇 | ↓ |
| الوقوف من الانزلاق | سحب لفوق | ↑ |
| مهارة خاصة (إنطلاقة) 💨 | ضغطة مطوّلة | D / Shift |
| إيقاف مؤقت | زر ⏸ | P / Esc |

## 4) عوائق الفصول (Obstacles)

| الفصل | العوائق | طريقة التجاوز |
|---|---|---|
| 🌸 الربيع | أغصان متدلية | انزلاق تحتها |
| 🌸 الربيع | نحل طائر (مسار جيبي) | توقيت القفز |
| 🌸 الربيع | برك طين | قفز (الوقوع فيها يُبطئك) |
| 🌸 الربيع | زهور متفجرة (تفتح وتغلق) | العبور وهي مغلقة |
| ☀️ الصيف | أعمدة نار (تحذير ثم اشتعال) | قفز فوق العمود |
| ☀️ الصيف | صبار متحرك | قفز فوقه |
| ☀️ الصيف | عدسات شمسية (شعاع حراري) | توقيت القفز فوق البقعة |
| ☀️ الصيف | عاصفة رملية (حدث جوي) | تقليل الرؤية مؤقتًا |
| 🍂 الخريف | أكوام أوراق تخفي عوائق | قفز فوق ما يُكشف |
| 🍂 الخريف | دوامات هوائية | القفز (لمسها يقذفك) |
| 🍂 الخريف | فطر سام متفجر | تجاوزه سريعًا |
| 🍂 الخريف | ثعلب يجري فجأة | قفز فوقه |
| ❄️ الشتاء | كتل جليد ساقطة (ظل تحذيري) | تجنب مكان السقوط |
| ❄️ الشتاء | رجل ثلج متحرك | قفز فوقه بالتوقيت |
| ❄️ الشتاء | دب نائم (يصحو ويطارد!) | اقفز فوقه أثناء المطاردة |
| ❄️ الشتاء | عاصفة ثلجية (حدث جوي) | تقليل الرؤية مؤقتًا |

## 5) القوى الخاصة (Power-ups)

| القوة | الأيقونة | التأثير |
|---|---|---|
| درع | 🛡️ | يمتص ضربة واحدة |
| مغناطيس | 🧲 | يجذب العملات والجواهر (10 ثوانٍ) |
| تجميد الزمن | ⏳ | يبطئ العالم حولك (5 ثوانٍ) |
| طيران النسر | 🦅 | تطير فوق كل العوائق (7 ثوانٍ) |
| تثبيت الفصل | 🔄 | يمنع تبديل الفصل (20 ثانية) |
| نجمة نورو | ⭐ | تدمر أي عائق تلمسه (8 ثوانٍ) |

**مهارة اللاعب الأساسية:** إنطلاقة 💨 (ضغطة مطوّلة) — اندفاع سريع مع حصانة قصيرة،
تتعاد كل 7 ثوانٍ.

## 6) العملات والتقدم (Currencies & Progression)

- 🍃 **أوراق الأشجار:** العملة الشائعة — تُجمع أثناء الجري، وتُستخدم لشراء **السكنات**.
- 💎 **شظايا الجوهرة:** عملة نادرة — تُضمن تقريبًا **كل 3 جولات**، وتفتح **القصة والفصول**.

### فتح الفصول (Progression Gates)
| الشظايا المطلوبة | الفصول المتاحة |
|---|---|
| 0 | 🌸 الربيع فقط |
| 1 | 🌸 + ☀️ |
| 3 | 🌸 + ☀️ + 🍂 |
| 5 | الفصول الأربعة كلها |

### شاشة الأرقام القياسية (Leaderboards)
- أفضل مسافة، أفضل نتيجة، أطول سلسلة (أفضل مسافة)، عدد الجولات،
  إجمالي الأوراق والجواهر، وأفضل 5 جولات محليًا.

## 8) القصة (Story)

- **مقدمة:** نورو تحرس جوهرة التوازن؛ ملك الفوضى يسرقها فتنكسر.
- **الفصل 1 — الربيع:** اجمع الشظايا من الحدائق المزهرة.
- **الفصل 2 — الصيف:** شمس حارقة وصحراء لا ترحم.
- **الفصل 3 — الخريف:** أوراق تخفي الأسرار ورياح تحمل الفوضى.
- **الفصل 4 — الشتاء:** الجليد يزحف؛ الشظية الأخيرة ومواجهة ملك الفوضى.
- **خاتمة:** تعود الفصول إلى إيقاعها… حتى تظهر شظية جديدة؟

---

## 9) الفن (Art Direction)

- **الأسلوب:** 2D مسطح مرسوم يدويًا (Flat / Hand-drawn)، ألوان جريئة وظلال ناعمة.
- **الأداء:** 60 إطارًا في الثانية، جزيئات كثيفة (غبار، شرارات، ثلج، أوراق، فراشات).
- **نورو:** كائن روحاني متوهج (Glow) بعيون كبيرة وخدود وردية، يتغير لونه مع الفصل.
- **انتقال الفصول:** تأثير **تمزق الورق** (Paper-tear) مع تلاشي الألوان.
- **الخلفيات:** سماء متدرجة، جبال بعيدة، طبقات Parallax، شمس/قمر، غيوم.

---

## 10) الصوت (Audio)

- **4 مسارات موسيقية** مولّدة برمجيًا (WebAudio — بدون ملفات):
  موسيقى مولّفة لكل فصل، مع **Crossfade** عند التحول.
- **مؤثرات صوتية:** قفز، قفز مزدوج، انزلاق، عملة، جوهرة، ضربة، انفجار،
  طاقة، تحول فصل، زر، عدّاد، نهاية اللعبة، رقم قياسي جديد.
- صوت/موسيقى يمكن كتمها من الإعدادات.

## 11) التقنية (Technical)

| المكوّن | التقنية |
|---|---|
| المحرك | HTML5 Canvas — بدون أي مكتبات خارجية |
| الصوت | WebAudio API (توليف مباشر) |
| الخطوط | Cairo (عربي/إنجليزي) + Lilita One (الشعار) — مضمّنة محليًا |
| الحفظ | localStorage |
| الـ APK | WebView wrapper + GitHub Actions (بناء تلقائي) |
| اللغة | العربية (RTL افتراضيًا) + English |
| الحجم | أقل من 5 MB (الحد الأقصى حسب GDD: 50 MB) |
